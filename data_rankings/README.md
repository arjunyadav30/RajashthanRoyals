# Player rankings

`RR_2027_All_838_Players_Master.csv` is the dashboard ranking source when present.
It contains role-specific all-player and qualified ranks, scores, and analysis
metrics. The backend reloads it when the file changes.

The separate `All_Batter_Rankings.csv` and `All_Bowler_Rankings.csv` files are
legacy fallback inputs for workspaces without the master file. Rankings are not
regenerated by `precompute.py`; supplied scores and ranks are consumed as-is.
